# Paco Morningstar's Witches' Companion

A free, offline grimoire: herbs, crystals, spells, sigils, oils, incense, tinctures, brews, deities, tarot and a live moon tracker.

**Download page:** https://pacogeist.github.io/WitchCompanion/

- **Android:** download the APK from the [latest release](https://github.com/PacoGeist/WitchCompanion/releases/latest). The app updates itself from this repository.
- **iPhone / iPad / computer:** open https://pacogeist.github.io/WitchCompanion/app/ in Safari and choose *Share → Add to Home Screen*.

Traditional and folk use only, not medical advice.
